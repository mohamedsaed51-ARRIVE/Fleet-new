# تحديث لوحة Fleet Support — هوية ARRIVE

## الملفات
| ملف | الحالة |
|---|---|
| `index.html` | أُعيد بناؤه (تصميم + عرض فقط). طبقة الاتصال `apiCall` ومنطق الفلاتر والتصدير كما هي. |
| `DesignSystem.html` | **جديد** — المصدر الوحيد للألوان والخطوط والمسافات والمكونات (لوحة + تقرير + طباعة). يُضمَّن بـ `include('DesignSystem')`. |
| `Assets.gs` | **جديد** — شعار ARRIVE الرسمي (PNG مصغّر 560px) كـ data URI. |
| `Reports.gs` | أُعيد تصميم تقرير الـ PDF من السيرفر (غلاف، ملخص، مؤشرات، تحليل، ملاحظات، توصيات، ختام). نفس `getManagementReportPdf` ونفس مصدر الأرقام `getReportsBundle`. |
| `Config.gs` | إضافة سطر واحد: `REPORT.ATTENTION_RESOLUTION_PCT = 50` (للعرض فقط). |
| `Backend.gs` `Code.gs` `Helpers.gs` | **بدون أي تعديل** (مطابقة بايت ببايت للأصل). |
| `legacy_untouched/` | Dashboard/Scripts/Styles — القديمة، لم تُلمس ولا يخدمها doGet. |
| `parts/` + `tools/build.py` | مصدر index.html (markup + app.js). `python3 tools/build.py` يعيد التجميع. |
| `tests/` | سكربتات الاختبار (باك إند حقيقي ببيانات تجريبية + Playwright) ولقطات. |

## الرفع
انسخ index.html و DesignSystem.html و Assets.gs و Reports.gs و Config.gs إلى مشروع Apps Script (الباقي كما هو) ثم أعد النشر.

## افتراضات ونقاط للتأكيد
1. **ألوان الحالة** (تحويل الفئات الثلاث لحالات الـ Design System): تم الحل = نجاح (أخضر)، قيد المتابعة = تحت الإجراء (كهرماني)، لم يتم الحل = مخالفة/حرجة (#EF4444). الربط في `BUCKET` داخل app.js.
2. **حد «يحتاج متابعة» 50%** لنسبة الحل: افتراض مني (غير موجود في الكود الأصلي) — عدّله في `Config.gs`. يُستخدم للعرض وللملاحظات فقط، لا يغيّر أي رقم.
3. **الملاحظات والتوصيات** في التقرير مستخرجة من أرقام الـ bundle فقط. الخطورة والسبب الجذري والإجراء والمسؤول والأولوية وتاريخ الاستحقاق **غير موجودة في Master Data** فتظهر «غير محدد بالمصدر». لو عايزها تتملى لازم أعمدة جديدة في الشيت.
4. **مفيش بيانات فترة سابقة** في الـ API، فكروت الـ KPI بدون سهم تغيّر. المقارنة بين شهرين موجودة في صفحتي الفروع والموظفين زي ما كانت.
5. تسمية كارت المقارنة «نسبة تغيّر نسبة الحل» كانت تحت عنوان خاطئ؛ الرقم الفعلي هو تغيّر **عدد المشاكل** فسُمّي «نسبة التغيّر في عدد المشاكل». الحساب لم يتغير.
6. صفوف Master Data بتاريخ غير صالح تُحسب في الإجمالي وتُستبعد من الجداول اليومية (سلوك الباك إند الأصلي). التقرير بقى يعرض ملاحظة بالفرق بدل ما يعرض مجموعين مختلفين بدون تفسير.

## حدود الاختبار
- الاختبار على الباك إند الحقيقي (`.gs` بدون تعديل) ببيانات **تجريبية** مولَّدة، 27 فحص وظيفي ناجح.
- خط Cairo غير متاح في بيئة الاختبار؛ اللقطات بخط عربي بديل. تحقق من الشكل النهائي في متصفحك.
- **PDF السيرفر** (`getAs('application/pdf')`) محوّل قديم لا أستطيع تشغيله هنا. بنيته على جداول وألوان صريحة لتناسبه، لكن لازم تجرّبه مرة بعد النشر. النسخة عالية الدقة هي صفحة التقارير ← طباعة.
- الشعار PNG وليس vector (مفيش SVG رسمي في الباكيج).
